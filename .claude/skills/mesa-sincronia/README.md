# mesa-sincronia

Skill de protocolo: mesa de sincronía multi-consola — identidad y firma con
aborto por nombre cruzado (§1–§2), leyenda TUI compactar-y-reemplazar (§3),
consentimiento (§4), modo tick con jerarquía de fuentes (§5), reparto (§6),
timbre con fallback pull (§7), hilos + git (§8), dinámica dirigida (§9),
cuadernos y cadena de sellos (§10), auditor en sombra (§11).

Activar desde el paquete; calibrar §0 en el consumidor (`CUSTODIO`, `HUB`,
`SALA`, `CARRILES`, `WORLD_ROOT(X)`, …). Datos de mesas reales → fuera de
este directorio; fixture sintético en `examples/`.

Capa operativa del carril: `reference/BUZON-Y-NOTAS.md` (buzón-puntero +
notas + montaje ejecutable) con plantillas en `reference/plantillas/`;
ciclo materializado hub + 2 carriles en `examples/fixture-buzones/` y CA de
montaje en `examples/simulacion-montaje-buzon.md`.

Ceguera del skill: `scripts/comprobar-ceguera.sh` → `ceguera: 0` (veto de
marcas de instancia y de marco; el vocabulario de método es propio).

Agente fresco: seguir solo `SKILL.md` + `reference/`.

Consumo canónico del paquete: README raíz del repo.
