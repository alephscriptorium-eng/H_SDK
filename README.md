# h-sdk — mundo H

Mundo consumidor del ecosistema scriptorium. **No es un holón** (la cadena
sigue en siete filas). Simula un **vendor externo**: usa `@zeus/*` y
`@alephscript/skills-scriptorium` desde el registry como tercero anónimo,
con `C:\S` como downstream y la obra en `C:\S_LAB`.

Hereda de NETWORK-ENGINE (Aleph) las **formas** — Bun, hexágono core/edges,
MODES, disciplina ADR — con corte genealógico registrado en
[`ADR/0001`](ADR/0001-genealogia-y-corte-network-engine.md). El doble acople
con zeus está en [`ADR/0002`](ADR/0002-doble-acople-aleph-zeus.md).
